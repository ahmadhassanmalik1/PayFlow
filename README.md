## ⚡ Overview

**PayFlow** is a client-side enterprise billing engine engineered to handle multi-currency conversions, tiered tax compliance structures (VAT, GST, WHT), and real-time audit ledger validation without round-trip server latency.

Built entirely without external billing libraries or server-side rendering, PayFlow executes floating-point financial arithmetic with rounded precision, dynamic QR verification hashing, and pixel-accurate print/PDF invoice rendering straight from the browser DOM.

---

## ✨ Key Capabilities

- **Real-Time Tax & Ledger Computation:**
  Automated multi-tier tax matrices including regional GST, value-added taxes (VAT), withholding tax (WHT), and configurable custom deductions with dynamic subtotal balancing.
- **Dynamic Multi-Currency Matrix:**
  Instantaneous cross-currency conversions and symbol formatting across global currencies (USD, EUR, GBP, PKR, AED, SAR) with tabular alignment.
- **Client-Side Vector PDF Engine:**
  Clean print-media stylesheet integrations (`@media print`) and DOM canvas capture for clean, high-resolution vector PDF export.
- **Cryptographic QR Validation:**
  Encodes transaction metadata, timestamps, and hash signatures directly into dynamic QR codes for physical/digital receipt audit trails.
- **Zero-Dependency Core:**
  Engineered with raw ES6+ modular JavaScript and semantic HTML5/CSS3 — zero external framework bloat, sub-second boot times, and full offline execution support.
